# دستورهای اولیه ترمینال لینوکس

در این درس با چند دستور ساده آشنا می‌شیم که برای شروع کار با ترمینال لینوکس بهشون نیاز داریم.

## ۱. نمایش مسیر فعلی با `pwd`

برای اینکه متوجه بشین در حال حاضر داخل چه پوشه‌ای هستین، از دستور `pwd` استفاده کنین.

:::terminal title="نمایش مسیر فعلی"
rootlab@linux:~$ pwd | نمایش مسیر پوشه‌ای که الان داخلش هستین
/home/rootlab
:::

## ۲. نمایش کاربر فعلی با `whoami`

برای اینکه بفهمین در حال حاضر با چه کاربری دارین دستورها رو اجرا می‌کنین، از `whoami` استفاده کنین.

:::terminal title="نمایش نام کاربر"
rootlab@linux:~$ whoami | نمایش نام کاربر فعلی
rootlab
:::

## ۳. تمیز کردن صفحه ترمینال با `clear`

گاهی بعد از اجرای چندین دستور، صفحه ترمینال خیلی شلوغ می‌شه. با `clear` می‌تونین صفحه رو تمیز کنین.

:::terminal title="پاک‌کردن نمایش ترمینال"
rootlab@linux:~$ clear | تمیز کردن صفحه ترمینال
:::

:::note نکته
دستور `clear` تاریخچه دستورهای قبلی رو پاک نمی‌کنه؛ فقط نمایش صفحه رو تمیز می‌کنه.
:::

## ۴. دیدن راهنمای ابزارها با `man` و `--help`

وقتی با ابزار جدیدی روبه‌رو می‌شین، معمولاً می‌تونین با `man` یا گزینه `--help` روش استفاده و گزینه‌هاش رو ببینین.

### راهنمای کامل‌تر با `man`

:::terminal title="نمایش راهنمای Nmap"
rootlab@linux:~$ man nmap | باز کردن صفحه راهنمای Nmap
NMAP(1)                      Nmap Reference Guide                      NMAP(1)
NAME
       nmap - Network exploration tool and security / port scanner
...
:::

داخل صفحه `man` معمولاً با کلیدهای جهت‌دار حرکت می‌کنین و با `q` خارج می‌شین.

### راهنمای سریع با `--help`

:::terminal title="نمایش گزینه‌های Nmap"
rootlab@linux:~$ nmap --help | نمایش راهنمای کوتاه و گزینه‌های Nmap
Nmap 7.x ( https://nmap.org )
Usage: nmap [Scan Type(s)] [Options] {target specification}
...
:::

:::tip تفاوت این دو روش
`man nmap` صفحه راهنمای مفصل‌تری رو باز می‌کنه؛ `nmap --help` معمولاً خلاصه‌ای از نحوه استفاده و گزینه‌های ابزار رو داخل ترمینال نشون می‌ده. همه برنامه‌ها لزوماً از هر دو روش پشتیبانی نمی‌کنن.
:::

## ۵. راهنمای دستورهای داخلی Bash با `help`

دستور `help` برای دیدن راهنمای **دستورهای داخلی Bash** استفاده می‌شه؛ مثلاً `cd` و `echo`.

:::terminal title="راهنمای داخلی Bash"
rootlab@linux:~$ help | فهرست دستورهای داخلی Bash
rootlab@linux:~$ help cd | نمایش راهنمای دستور داخلی cd
:::

:::important دقت کنین
`help nmap` در Bash راهنمای Nmap رو نمایش نمی‌ده، چون Nmap دستور داخلی Bash نیست. برای Nmap از `man nmap` یا `nmap --help` استفاده کنین.
:::

## ۶. نمایش متن با `echo`

با دستور `echo` می‌تونین متن دلخواهتون رو داخل ترمینال نمایش بدین.

:::terminal title="چاپ متن در ترمینال"
rootlab@linux:~$ echo "hello world" | نمایش یک متن ساده
hello world
:::

## ۷. مشاهده تاریخچه دستورها با `history`

برای دیدن دستورهایی که قبلاً در Shell اجرا کردین، از `history` استفاده کنین.

:::terminal title="نمایش تاریخچه دستورها"
rootlab@linux:~$ history | نمایش فهرست دستورهای ثبت‌شده
  1  pwd
  2  whoami
  3  echo "hello world"
  4  history
:::

:::note نکته
خروجی `history` به تنظیمات Bash و تاریخچه نشست فعلی یا نشست‌های قبلی بستگی داره؛ بنابراین ممکنه روی سیستم شما متفاوت باشه.
:::

## مرور سریع دستورها

| دستور | کاربرد |
| --- | --- |
| `pwd` | نمایش مسیر پوشه فعلی |
| `whoami` | نمایش نام کاربر فعلی |
| `clear` | تمیز کردن صفحه ترمینال |
| `man nmap` | باز کردن صفحه راهنمای Nmap |
| `nmap --help` | نمایش راهنمای سریع Nmap |
| `help` | نمایش فهرست دستورهای داخلی Bash |
| `help cd` | نمایش راهنمای دستور داخلی `cd` |
| `echo "hello world"` | نمایش متن در ترمینال |
| `history` | نمایش تاریخچه دستورها |
