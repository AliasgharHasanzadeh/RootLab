# مسیریابی و شناخت فایل‌سیستم لینوکس

در درس قبل با دستور `pwd` آشنا شدین. حالا یاد می‌گیرین چطور بین پوشه‌ها جابه‌جا بشین، محتویاتشون رو ببینین و مسیر فایل‌ها رو درست بنویسین.

## ۱. ساختار مسیرها در لینوکس

همه مسیرهای لینوکس از پوشه اصلی `/` شروع می‌شن. به این پوشه **Root Directory** می‌گن؛ با کاربر `root` فرق داره.

مثلاً مسیر `/home/rootlab/Documents` یعنی پوشه `Documents` داخل پوشه کاربر `rootlab` در مسیر `/home` قرار گرفته.

| مسیر | کاربرد |
| --- | --- |
| `/` | ریشه فایل‌سیستم؛ شروع همه مسیرها |
| `/home` | پوشه‌های شخصی کاربران معمولی |
| `/root` | پوشه شخصی کاربر مدیریتی `root` |
| `/etc` | بسیاری از فایل‌های تنظیمات سیستم و سرویس‌ها |
| `/var` | داده‌های متغیر مثل لاگ‌ها در `/var/log` |
| `/tmp` | فایل‌های موقت؛ ماندگاری فایل‌ها در آن تضمین‌شده نیست |
| `/usr` | بخش بزرگی از برنامه‌ها، کتابخانه‌ها و فایل‌های اشتراکی سیستم |
| `/opt` | محل رایج نصب بعضی نرم‌افزارهای جانبی |
| `/dev` | فایل‌های مربوط به دستگاه‌ها |
| `/proc` | اطلاعات مجازی مربوط به فرآیندها و کرنل |
| `/sys` | اطلاعات و رابط‌های مجازی دستگاه‌ها و کرنل |

:::note نکته
قرار نیست این مسیرها رو حفظ کنین. فعلاً بدونین هرکدوم چه کاربردی دارن؛ در درس‌های بعدی مرتب باهاشون کار می‌کنیم.
:::

## ۲. جابه‌جایی بین پوشه‌ها با `cd`

دستور `cd` مخفف **Change Directory** هست و پوشه فعلی ترمینال رو تغییر می‌ده.

:::terminal title="ورود به یک پوشه"
rootlab@linux:~$ cd /var/log | رفتن به پوشه لاگ‌های سیستم
rootlab@linux:/var/log$ pwd | بررسی مسیر فعلی
/var/log
:::

### مسیر مطلق و مسیر نسبی

- **مسیر مطلق (Absolute Path):** از `/` شروع می‌شه و به پوشه فعلی شما وابسته نیست؛ مثل `/home/rootlab/Documents`.
- **مسیر نسبی (Relative Path):** نسبت به پوشه‌ای که الان داخلش هستین تفسیر می‌شه؛ مثل `Documents` یا `../Downloads`.

:::terminal title="مقایسه مسیر مطلق و نسبی"
rootlab@linux:~$ pwd
/home/rootlab
rootlab@linux:~$ cd Documents | ورود با مسیر نسبی
rootlab@linux:~/Documents$ pwd
/home/rootlab/Documents
rootlab@linux:~/Documents$ cd /var/log | ورود با مسیر مطلق
rootlab@linux:/var/log$ pwd
/var/log
:::

### میان‌برهای مهم `cd`

| دستور | نتیجه |
| --- | --- |
| `cd /` | رفتن به ریشه فایل‌سیستم |
| `cd` یا `cd ~` | رفتن به پوشه شخصی کاربر فعلی |
| `cd ..` | رفتن به پوشه والد، یک سطح بالاتر |
| `cd .` | ماندن در پوشه فعلی |
| `cd -` | برگشتن به مسیر قبلی |
| `cd ../Documents` | رفتن یک سطح بالاتر و سپس ورود به `Documents` |

:::terminal title="کار با میان‌برهای مسیر"
rootlab@linux:~$ cd /home/rootlab/Documents
rootlab@linux:~/Documents$ cd .. | رفتن به پوشه والد
rootlab@linux:~$ pwd
/home/rootlab
rootlab@linux:~$ cd - | برگشت به مسیر قبلی
/home/rootlab/Documents
:::

:::important تفاوت `/`، `~`، `.` و `..`
`/` ریشه کل فایل‌سیستمه؛ `~` پوشه شخصی کاربر فعلیه؛ `.` یعنی همین پوشه؛ و `..` یعنی پوشه والد. این چهار مورد رو با هم اشتباه نگیرین.
:::

## ۳. نمایش محتویات پوشه با `ls`

دستور `ls` فایل‌ها و پوشه‌های یک مسیر رو فهرست می‌کنه. بدون آرگومان، محتویات پوشه فعلی رو نشون می‌ده.

:::terminal title="فهرست محتویات پوشه"
rootlab@linux:~$ ls | نمایش فایل‌ها و پوشه‌های مسیر فعلی
Desktop  Documents  Downloads  notes.txt
rootlab@linux:~$ ls /etc | نمایش محتویات یک مسیر مشخص
apt  hostname  hosts  passwd  ssh
:::

### گزینه‌های پرکاربرد `ls`

| گزینه | کاربرد |
| --- | --- |
| `-l` | نمایش جزئیات هر مورد؛ مثل مجوزها، مالک، اندازه و زمان تغییر |
| `-a` | نمایش فایل‌های مخفی؛ حتی `.` و `..` |
| `-A` | نمایش فایل‌های مخفی به‌جز `.` و `..` |
| `-h` | نمایش اندازه خواناتر مثل `K` و `M`؛ معمولاً همراه `-l` |
| `-R` | نمایش بازگشتی محتویات زیرپوشه‌ها |
| `-t` | مرتب‌سازی بر اساس زمان آخرین تغییر، جدیدترها اول |
| `-S` | مرتب‌سازی بر اساس اندازه، بزرگ‌ترها اول |
| `-r` | برعکس کردن ترتیب مرتب‌سازی |
| `-d` | نمایش خود پوشه به‌جای محتویاتش؛ مفید همراه `-l` |

:::terminal title="چند نمونه از گزینه‌های ls"
rootlab@linux:~$ ls -l | نمایش جزئیات
rootlab@linux:~$ ls -a | نمایش فایل‌های مخفی
rootlab@linux:~$ ls -lh | جزئیات با اندازه خوانا
rootlab@linux:~$ ls -lah | ترکیب سه گزینه پرکاربرد
rootlab@linux:~$ ls -lt | مرتب‌سازی بر اساس زمان تغییر
rootlab@linux:~$ ls -lS | مرتب‌سازی بر اساس اندازه
rootlab@linux:~$ ls -R Documents | نمایش زیرپوشه‌ها به‌صورت بازگشتی
:::

گزینه‌ها رو می‌تونین ترکیب کنین؛ مثلاً `ls -l -a -h` و `ls -lah` نتیجه یکسانی دارن.

:::tip انتخاب سریع
برای بررسی معمول فایل‌ها، `ls -lah` یکی از کاربردی‌ترین ترکیب‌هاست. فقط یادتون باشه `-h` به‌تنهایی اندازه فایل رو نمایش نمی‌ده؛ اندازه در خروجی مفصل `-l` دیده می‌شه.
:::

### خواندن خروجی `ls -l`

:::terminal title="نمونه خروجی ls -l"
rootlab@linux:~$ ls -l
total 8
drwxr-xr-x 2 rootlab rootlab 4096 Oct 29 09:00 Documents
-rw-r--r-- 1 rootlab rootlab   42 Oct 29 08:30 notes.txt
:::

مثلاً در خط `notes.txt`:

| بخش | معنی |
| --- | --- |
| `-rw-r--r--` | نوع فایل و مجوزهای دسترسی |
| `1` | تعداد پیوندهای سخت (Hard Links) |
| `rootlab` اول | مالک فایل |
| `rootlab` دوم | گروه فایل |
| `42` | اندازه فایل بر حسب بایت |
| `Oct 29 08:30` | زمان آخرین تغییر محتوا |
| `notes.txt` | نام فایل |

در ابتدای مجوزها، `-` یعنی فایل معمولی و `d` یعنی پوشه. معنی دقیق `r`، `w` و `x` رو در فصل مجوزهای لینوکس یاد می‌گیرین.

:::note نکته
عدد `total` جمع اندازه فایل‌ها بر حسب بایت نیست؛ معمولاً تعداد بلوک‌های تخصیص‌یافته برای موارد نمایش‌داده‌شده رو بیان می‌کنه. مقدارش می‌تونه بین سیستم‌ها متفاوت باشه.
:::

## ۴. فایل‌های مخفی و الگوهای نام فایل

در لینوکس، نام‌هایی که با نقطه شروع می‌شن معمولاً در خروجی ساده `ls` دیده نمی‌شن؛ مثل `.bashrc`.

:::terminal title="نمایش فایل‌های مخفی"
rootlab@linux:~$ ls -a
.  ..  .bashrc  .profile  Desktop  Documents  Downloads  notes.txt
:::

برای انتخاب چند فایل با یک الگو، Shell از **Wildcard** استفاده می‌کنه:

| الگو | معنی |
| --- | --- |
| `*` | صفر یا چند کاراکتر |
| `?` | دقیقاً یک کاراکتر |
| `*.txt` | نام‌هایی که به `.txt` ختم می‌شن |
| `file?.txt` | مثل `file1.txt` یا `fileA.txt`، ولی نه `file10.txt` |

:::terminal title="فهرست فایل‌ها با الگو"
rootlab@linux:~$ ls *.txt | نمایش فایل‌های txt در پوشه فعلی
notes.txt
rootlab@linux:~$ ls Documents/*.pdf | نمایش PDFهای پوشه Documents
Documents/guide.pdf
:::

:::note رفتار فایل‌های مخفی
الگوی `*` در Bash به‌صورت پیش‌فرض نام‌هایی رو که با نقطه شروع می‌شن انتخاب نمی‌کنه. برای دیدن فایل‌های مخفی از `ls -a` استفاده کنین.
:::

## ۵. مسیرهایی که فاصله دارن

اگه اسم فایل یا پوشه فاصله داشته باشه، مسیر رو داخل کوتیشن قرار بدین یا فاصله رو با `\` مشخص کنین.

:::terminal title="ورود به پوشه با نام چندکلمه‌ای"
rootlab@linux:~$ cd "My Projects" | روش اول: کوتیشن
rootlab@linux:~/My Projects$ cd ..
rootlab@linux:~$ cd My\ Projects | روش دوم: escape کردن فاصله
:::

بدون این کار، Shell عبارت `My Projects` رو به دو آرگومان جدا تقسیم می‌کنه و دستور معمولاً خطا می‌ده.

## ۶. نمایش ساختار درختی و مسیر کامل

این دو ابزار برای مشاهده مسیرها مفیدن، ولی ممکنه روی بعضی توزیع‌ها از قبل نصب نباشن.

:::terminal title="ساختار درختی پوشه‌ها"
rootlab@linux:~$ tree Documents | نمایش فایل‌ها و زیرپوشه‌ها به شکل درختی
Documents
├── guide.pdf
└── Projects
    └── notes.txt
:::

:::terminal title="تبدیل مسیر نسبی به مسیر مطلق"
rootlab@linux:~$ realpath Documents/guide.pdf
/home/rootlab/Documents/guide.pdf
:::

`tree` ساختار پوشه رو خواناتر نشون می‌ده و `realpath` مسیر کامل و نهایی یک فایل یا پوشه رو به دست می‌ده.

## مرور سریع دستورها

| دستور | کاربرد |
| --- | --- |
| `pwd` | نمایش مسیر فعلی |
| `cd /var/log` | رفتن به مسیر مطلق |
| `cd Documents` | رفتن به مسیر نسبی |
| `cd ..` | یک پوشه بالاتر |
| `cd ~` | رفتن به پوشه شخصی |
| `cd -` | برگشتن به مسیر قبلی |
| `ls` | فهرست محتویات پوشه |
| `ls -lah` | نمایش جزئیات، فایل‌های مخفی و اندازه خوانا |
| `ls -R` | فهرست بازگشتی زیرپوشه‌ها |
| `ls *.txt` | نمایش فایل‌های منطبق با الگو |
| `tree` | نمایش ساختار درختی |
| `realpath` | نمایش مسیر مطلق و نهایی |

:::warning خطاهای رایج
- اگه `cd` خطای `No such file or directory` داد، مسیر یا نام پوشه رو بررسی کنین.
- اگه `Permission denied` دیدین، ممکنه اجازه ورود به اون پوشه رو نداشته باشین.
- اگه `ls *.txt` خطا داد، ممکنه در پوشه فعلی فایل منطبق با الگو وجود نداشته باشه.
:::
