# مدیریت فایل‌ها و پوشه‌ها در لینوکس

توی فصل قبل یاد گرفتین چطور بین پوشه‌ها جابه‌جا بشین. حالا می‌خوایم فایل و پوشه بسازیم، کپی و منتقلشون کنیم، حذفشون کنیم و فایل‌های موردنظرمون رو پیدا کنیم.

:::tip محیط تمرین
مثال‌ها رو داخل پوشه شخصی خودتون انجام بدین؛ نه داخل مسیرهای مهم سیستم.
:::

## ۱. ساخت فایل با `touch`

دستور `touch` برای ساخت فایل خالی کاربرد داره. اگه فایل از قبل وجود داشته باشه، محتواش پاک نمی‌شه؛ زمان‌های دسترسی و تغییر فایل به‌روزرسانی می‌شن.

:::terminal title="ساخت فایل"
rootlab@linux:~$ touch notes.txt | ساخت یک فایل خالی
rootlab@linux:~$ touch one.txt two.txt | ساخت دو فایل
rootlab@linux:~$ ls *.txt
notes.txt  one.txt  two.txt
:::

## ۲. ساخت پوشه با `mkdir`

`mkdir` مخفف **Make Directory** هست.

:::terminal title="ساخت پوشه"
rootlab@linux:~$ mkdir Projects | ساخت پوشه
rootlab@linux:~$ mkdir -p Projects/Linux/Notes | ساخت پوشه‌های تودرتو
:::

| گزینه | کاربرد |
| --- | --- |
| `-p` | ساخت پوشه‌های والد در صورت نبودن؛ اگر پوشه مقصد موجود باشه خطای معمول ایجاد نمی‌کنه |
| `-v` | نمایش پیام هنگام ساخت پوشه |

بدون `-p`، اگر پوشه‌های میانی وجود نداشته باشن، ساخت مسیر تودرتو خطا می‌ده.

## ۳. کپی فایل و پوشه با `cp`

`cp` مخفف **Copy** هست و یک نسخه جدید از فایل یا پوشه ایجاد می‌کنه؛ نسخه اصلی باقی می‌مونه.

```bash
cp SOURCE DESTINATION
```

:::terminal title="کپی فایل"
rootlab@linux:~$ cp notes.txt backup.txt | ساخت کپی با نام جدید
rootlab@linux:~$ cp notes.txt Projects/ | کپی به داخل پوشه
:::

برای کپی پوشه به همراه محتویاتش باید از `-r` استفاده کنین.

:::terminal title="کپی پوشه"
rootlab@linux:~$ cp -r Projects Projects-Backup
:::

| گزینه | کاربرد |
| --- | --- |
| `-r` یا `-R` | کپی بازگشتی پوشه و تمام محتویات |
| `-i` | درخواست تأیید قبل از بازنویسی فایل مقصد |
| `-n` | بازنویسی نکردن فایل موجود در مقصد |
| `-v` | نمایش عملیات کپی |
| `-a` | کپی آرشیوی و بازگشتی با حفظ ویژگی‌هایی مثل مالکیت، مجوز و زمان‌ها تا حد امکان |

:::important مقصد کپی
اگه مقصد یک **پوشه موجود** باشه، فایل داخل اون پوشه کپی می‌شه. اگه مقصد یک **فایل موجود** باشه، ممکنه محتوای قبلیش بازنویسی بشه. برای گرفتن تأیید از `cp -i` استفاده کنین.
:::

## ۴. جابه‌جایی و تغییر نام با `mv`

دستور `mv` مخفف **Move** هست. هم برای انتقال فایل و پوشه استفاده می‌شه، هم برای تغییر نام.

:::terminal title="تغییر نام و انتقال"
rootlab@linux:~$ mv notes.txt lesson.txt | تغییر نام فایل
rootlab@linux:~$ mv lesson.txt Projects/ | انتقال فایل به Projects
rootlab@linux:~$ mv Projects-Backup Old-Projects | تغییر نام پوشه
:::

| گزینه | کاربرد |
| --- | --- |
| `-i` | تأیید قبل از بازنویسی مقصد |
| `-n` | بازنویسی نکردن مقصد موجود |
| `-v` | نمایش عملیات انجام‌شده |

**تفاوت `cp` و `mv`:** دستور `cp` نسخه اصلی رو نگه می‌داره، ولی `mv` فایل یا پوشه رو به نام یا مسیر جدید منتقل می‌کنه.

:::warning نکته
`mv` هم ممکنه فایل مقصد موجود رو جایگزین کنه. برای جلوگیری از اشتباه، قبل از انتقال مقصد رو بررسی کنین یا از `mv -i` استفاده کنین.
:::

## ۵. حذف فایل با `rm`

`rm` مخفف **Remove** هست و برای حذف فایل استفاده می‌شه.

:::terminal title="حذف فایل‌های تمرینی"
rootlab@linux:~$ rm backup.txt | حذف یک فایل
rootlab@linux:~$ rm one.txt two.txt | حذف چند فایل
:::

| گزینه | کاربرد |
| --- | --- |
| `-i` | درخواست تأیید برای حذف |
| `-r` یا `-R` | حذف بازگشتی پوشه و محتویات |
| `-f` | حذف بدون درخواست تأیید معمول و نادیده گرفتن فایل ناموجود |
| `-v` | نمایش نام موارد حذف‌شده |

:::danger مراقب حذف فایل‌ها باشین
`rm` معمولاً فایل رو به سطل زباله منتقل نمی‌کنه و بازیابی ساده‌ای نداره. مخصوصاً هنگام استفاده از `-r` و `-f` مسیر رو با `pwd` و `ls` بررسی کنین.
:::

## ۶. حذف پوشه با `rmdir` و `rm -r`

`rmdir` فقط **پوشه خالی** رو حذف می‌کنه. برای حذف پوشه‌ای که محتوا داره، `rm -r` وجود داره.

:::terminal title="حذف پوشه"
rootlab@linux:~$ mkdir EmptyFolder
rootlab@linux:~$ rmdir EmptyFolder | حذف پوشه خالی
rootlab@linux:~$ rm -ri Old-Projects | حذف بازگشتی همراه با تأیید
:::

| دستور | کاربرد |
| --- | --- |
| `rmdir Folder` | حذف پوشه خالی |
| `rm -r Folder` | حذف پوشه و تمام محتویاتش |
| `rm -ri Folder` | حذف بازگشتی با درخواست تأیید |

:::tip
اگه فقط می‌خواین پوشه خالی رو حذف کنین، `rmdir` امن‌تره؛ چون پوشه دارای محتوا رو حذف نمی‌کنه.
:::

## ۷. تشخیص نوع فایل با `file`

پسوند فایل همیشه نوع واقعی اون رو مشخص نمی‌کنه. `file` با بررسی محتوای فایل، نوع احتمالی اون رو تشخیص می‌ده.

:::terminal title="تشخیص نوع فایل"
rootlab@linux:~$ file Projects/lesson.txt
Projects/lesson.txt: empty
:::

خروجی بسته به محتوا و نوع فایل متفاوته.

## ۸. اطلاعات دقیق فایل با `stat`

دستور `stat` اطلاعاتی مثل اندازه، مالک، گروه، مجوزها و زمان‌های فایل رو نمایش می‌ده.

:::terminal title="اطلاعات فایل"
rootlab@linux:~$ stat Projects/lesson.txt
  File: Projects/lesson.txt
  Size: 0               Blocks: 0
Access: (0644/-rw-r--r--)  Uid: (1000/rootlab)  Gid: (1000/rootlab)
:::

| فیلد | معنی |
| --- | --- |
| `Access` (زمان) | آخرین زمان دسترسی؛ بسته به تنظیمات سیستم ممکنه همیشه ثبت نشه |
| `Modify` | آخرین تغییر محتوای فایل |
| `Change` | آخرین تغییر اطلاعات inode، مثل مجوزها و مالکیت، یا محتوا |
| `Birth` | زمان ایجاد فایل، در صورت پشتیبانی فایل‌سیستم |

:::note
`Change` به معنی زمان ساخت فایل نیست؛ با `Birth` فرق داره.
:::

## ۹. جست‌وجوی فایل‌ها با `find`

دستور `find` از یک مسیر شروع می‌کنه و فایل‌ها و پوشه‌ها رو با شرط‌های مشخص جست‌وجو می‌کنه.

```bash
find PATH CONDITIONS
```

:::terminal title="پیدا کردن فایل"
rootlab@linux:~$ find Projects -name "lesson.txt" | جست‌وجوی نام دقیق
Projects/lesson.txt
rootlab@linux:~$ find Projects -type f | نمایش فایل‌های معمولی
rootlab@linux:~$ find Projects -type d | نمایش پوشه‌ها
:::

### شرط‌های کاربردی `find`

| گزینه | کاربرد |
| --- | --- |
| `-name "*.txt"` | جست‌وجوی نام‌های منطبق با الگو؛ حساس به حروف بزرگ و کوچک |
| `-iname "*.txt"` | مثل `-name`، اما بدون حساسیت به بزرگی و کوچکی حروف |
| `-type f` | فقط فایل‌های معمولی |
| `-type d` | فقط پوشه‌ها |
| `-mtime -7` | فایل‌هایی که محتوای اون‌ها در کمتر از ۷ روز گذشته تغییر کرده |
| `-size +10M` | فایل‌های بزرگ‌تر از ۱۰ واحد MiB طبق قاعده گردکردن `find` |
| `-maxdepth 1` | جست‌وجو فقط در مسیر شروع و بدون ورود به زیرپوشه‌ها |

:::terminal title="مثال‌های کاربردی find"
rootlab@linux:~$ find Projects -iname "*.txt" | جست‌وجوی فایل‌های txt
rootlab@linux:~$ find Projects -type f -mtime -7 | فایل‌های اخیراً تغییرکرده
rootlab@linux:~$ find Projects -maxdepth 1 -type f | فایل‌های سطح اول Projects
:::

:::important تفاوت `ls` و `find`
`ls` محتویات یک پوشه رو فهرست می‌کنه؛ `find` می‌تونه با شرط‌هایی مثل نام، نوع و زمان، داخل مسیر و زیرپوشه‌ها جست‌وجو کنه.
:::

## ۱۰. مسیرهایی که فاصله دارن

اگه اسم فایل یا پوشه فاصله داشته باشه، مسیر رو داخل کوتیشن بذارین.

:::terminal title="نام‌های دارای فاصله"
rootlab@linux:~$ mkdir "My Projects"
rootlab@linux:~$ touch "My Projects/first note.txt"
rootlab@linux:~$ cp "My Projects/first note.txt" "My Projects/backup note.txt"
rootlab@linux:~$ mv "My Projects/backup note.txt" "My Projects/final note.txt"
:::

راه دیگه escape کردن فاصله با `\` هست؛ ولی کوتیشن برای شروع خواناتر و ساده‌تره.

## مرور سریع فصل

| دستور | کاربرد |
| --- | --- |
| `touch file.txt` | ساخت فایل خالی یا تغییر timestamp |
| `mkdir Folder` | ساخت پوشه |
| `mkdir -p A/B` | ساخت پوشه‌های تودرتو |
| `cp a.txt b.txt` | کپی فایل |
| `cp -r A B` | کپی پوشه |
| `mv a.txt b.txt` | تغییر نام یا انتقال |
| `rm file.txt` | حذف فایل |
| `rmdir Folder` | حذف پوشه خالی |
| `rm -ri Folder` | حذف بازگشتی همراه با تأیید |
| `file file.txt` | تشخیص نوع فایل |
| `stat file.txt` | اطلاعات دقیق فایل |
| `find . -name "*.txt"` | جست‌وجو بر اساس نام |

:::warning خطاهای رایج
- `No such file or directory`: مسیر یا نام فایل/پوشه اشتباهه.
- `Permission denied`: مجوز لازم رو ندارین.
- `Is a directory`: دارین با دستوری که انتظار فایل داره، روی پوشه کار می‌کنین.
- `Directory not empty`: پوشه خالی نیست و `rmdir` نمی‌تونه حذفش کنه.
- `File exists`: فایل یا پوشه مقصد از قبل وجود داره.
:::
